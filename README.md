# Renovate hands-on – Companion Code

Companion code for the book **Renovate hands-on** (German edition: *Renovate zum Anfassen*) – keeping dependencies up to date automatically, without drowning in PRs. Part of Thomas Zachmann's IT Drills series.

Book page: https://itdrills.com/books/renovate · German edition: https://it-trainingslager.de/buecher/renovate

The code accompanies the book; explanations and exercises are in the book.

## Quick start

```bash
git clone https://github.com/thomaszachmann/renovate-zum-anfassen.git
```

On Day 0 you copy the companion code to `~/renovate-lab/code` – details are in the book's "Day 0" chapter.
